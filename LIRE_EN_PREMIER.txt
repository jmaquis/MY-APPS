MY APPS • Windows

SI VOUS UTILISEZ DÉJÀ MY APPS
Fermez MY APPS et décompressez cette archive dans le dossier qui contient
déjà MY_APPS.cmd. Acceptez le remplacement des fichiers de même nom,
puis relancez MY_APPS.cmd. Vos applications locales et vos raccourcis
sont retrouvés depuis le même compte Windows.

PREMIER LANCEMENT
1. Décompressez le ZIP MY_APPS_Windows dans un dossier de votre choix.
2. Ouvrez ce dossier et double-cliquez sur MY_APPS.cmd.
3. Cliquez sur « Importer un pack ZIP… » et sélectionnez Demo_Mes_Notes.zip.
   Le pack de démonstration doit rester au format ZIP.
4. Cliquez sur « Ouvrir » dans la tuile Mes notes. Saisissez une note,
   puis fermez et rouvrez la page dans le même navigateur pour vérifier
   la conservation de la note.

BIBLIOTHÈQUE
Utilisez la barre de recherche pour retrouver une application par son nom.
La colonne de gauche permet d’afficher toutes les applications, les applications
stockées localement ou les raccourcis.

AJOUTER UN FICHIER
Sélectionnez un fichier HTML ou HTM autonome avec « Ajouter un fichier ».
MY APPS le copie dans son dossier Applications. La carte « HTML local »
ouvre cette copie. Si vous sélectionnez de nouveau le fichier au même
emplacement, MY APPS propose de remplacer la copie locale.
Pour une application fournie avec des fichiers CSS, JS ou images externes,
utilisez un pack ZIP MY APPS contenant l’ensemble de ses fichiers.

« Supprimer » demande confirmation avant de retirer un raccourci ou
d’effacer les fichiers d’une application installée dans MY APPS.
« Ajouter un fichier » enregistre un raccourci pour les fichiers EXE.
Les anciens raccourcis HTML restent disponibles. Pour obtenir une copie
locale, sélectionnez de nouveau votre fichier HTML via « Ajouter un fichier ».
Les données enregistrées dans le navigateur peuvent être liées à l’ancien
chemin. Si l’application propose un export, exportez depuis l’ancienne
version, puis importez depuis la copie locale.
Le launcher ouvre le HTML avec le navigateur par défaut de Windows.

METTRE À JOUR LE LAUNCHER
MY APPS vérifie les versions disponibles sur GitHub au démarrage.
Si le menu de gauche propose « Installer la v… », cliquez sur ce bouton
et confirmez. Fermez puis relancez MY APPS pour utiliser la nouvelle version.
Utilisez « Vérifier les mises à jour » pour interroger GitHub à nouveau,
ou « Installer un ZIP » si vous avez déjà téléchargé le ZIP de mise à jour.
La version en cours figure sous les boutons. MY APPS peut ouvrir la version
précédente si la nouvelle échoue au démarrage.

CATALOGUE GITHUB
Le catalogue de jmaquis/MY-APPS est vérifié à l’ouverture. Les applications
disponibles s’affichent sur l’accueil « Mes applications ». Cliquez sur
« Installer l’application » pour télécharger et installer le pack GitHub.
Après l’installation, le bouton « Ouvrir » permet de lancer l’application.
L’alerte ouvre le catalogue, où les nouveautés et mises à jour sont listées.
Les applications déjà installées peuvent proposer le bouton « Mettre à jour ».
Utilisez « Actualiser » dans le catalogue pour interroger GitHub à nouveau.
Gardez le même navigateur et profil pour retrouver les données de vos applis.

Une application du catalogue est identifiée par l’id de son pack ZIP.
Un fichier importé directement comme « HTML local » reste une copie séparée.
L’accès au catalogue nécessite Internet. Les applications installées
restent accessibles depuis le launcher quand GitHub est indisponible.

APPLICATIONS ET PACKS ZIP
Importez le ZIP fourni pour MY APPS. Pour une mise à jour, importez le
nouveau ZIP de cette application. MY APPS la reconnaît par son identifiant
et demande votre accord avant le remplacement. Son adresse locale reste
la même. Les applications HTML gèrent leurs propres données et exports.
Utilisez la fonction d’export de l’application lorsqu’elle en propose une.

INFORMATIONS TECHNIQUES
Le launcher utilise Windows PowerShell avec une interface graphique.
Il ne nécessite ni compte ni connexion pour démarrer. Le fichier CMD lance
le script avec une règle d’exécution limitée au processus PowerShell ouvert
pour MY APPS. Les réglages de la machine restent tels quels.
Les applications et les raccourcis sont stockés dans
%LOCALAPPDATA%\MY_APPS.
Gardez MY_APPS.cmd, MY_APPS.ps1, MY_APPS_App.ps1 et MY_APPS.xaml dans
le même dossier.

FORMAT D’UN PACK
À la racine du ZIP, placez index.html et my-apps.json, ainsi que les
fichiers utilisés par l’application. Exemple de manifeste :
{"schema":1,"id":"mon-appli","name":"Mon appli","version":"1.0.0"}
Conservez le même identifiant pour les mises à jour. Pour un usage hors
ligne, incluez les ressources utilisées par la page dans le ZIP.
