À savoir sur le fonctionnement local

Aucune donnée n’est envoyée par cette application. Les notes et pièces jointes sont stockées dans ce navigateur sur cet appareil, pas dans le fichier HTML. Réutilise le même fichier et le même navigateur. Le stockage des fichiers locaux dépend du navigateur ; certains lecteurs sur téléphone ne le permettent pas.

Effacer les données du navigateur, changer de navigateur ou perdre l’appareil peut faire perdre ton carnet. Fais régulièrement une sauvegarde et conserve aussi les documents originaux. Le carnet et les nouvelles sauvegardes ne sont pas chiffrés ni protégés par un mot de passe. Toute personne ayant accès à cet appareil peut les consulter. Les anciennes sauvegardes chiffrées nécessitent encore leur ancien mot de passe pour être importées. Ce carnet personnel n’est pas un dossier médical officiel.

Enregistrer la sauvegarde

Ce navigateur ne permet pas de choisir directement un dossier. Tu peux utiliser les options de partage de ton appareil ou le téléchargement habituel.

Dans le partage, choisis « Enregistrer dans Fichiers » ou un gestionnaire de fichiers, si cette option est proposée. Sinon, le dossier dépend des réglages de téléchargement de ton navigateur.
