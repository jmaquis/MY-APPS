# MY APPS

MY APPS est un launcher Windows pour organiser et ouvrir ses applications locales. Il peut importer des fichiers HTML autonomes, des packs ZIP MY APPS et des raccourcis vers des exécutables.

## Télécharger et lancer

1. Ouvrez la [dernière version](../../releases/latest) et téléchargez le ZIP Windows dans **Assets**.
2. Décompressez le ZIP dans un dossier de votre choix.
3. Double-cliquez sur `MY_APPS.cmd`.

Les applications installées et les raccourcis sont stockés dans le profil Windows. Le launcher fonctionne localement.

## Mettre à jour

Dans MY APPS, cliquez sur **Mettre à jour MY APPS**, sélectionnez le ZIP de mise à jour du launcher fourni pour la nouvelle version, puis fermez et relancez MY APPS. Les packs d’applications s’installent via **Importer un pack ZIP**.

Le fichier [LIRE_EN_PREMIER.txt](LIRE_EN_PREMIER.txt) détaille les formats de packs, l’installation et les mises à jour.
